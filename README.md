# Weather App

A React weather app that searches for a city and shows its current temperature, weather conditions, state or region, country, and five-day forecast. Weather data is provided by Open-Meteo.

## Run locally

1. Install [Node.js](https://nodejs.org/).
2. Download or clone this repository.
3. Open a terminal in the project folder and run:

   ```bash
   npm install
   npm run dev
   ```

4. Open the local address printed in the terminal.

## Weather data

The app uses the Open-Meteo Geocoding API to find cities and the Open-Meteo Forecast API for current conditions and the five-day forecast. No API key is required for this app’s use.
